# Contributing

Read README.md and AGENTS.md before making changes. Use your own development services and an isolated checkout. Never connect a contribution to Revline's production deployment.

Keep changes focused and open a pull request against main. Explain the behavior change and any remaining limitations. Run `npm run typecheck` and `npm run build`; inspect the relevant running behavior. This repository intentionally does not add test-only files.

Do not commit environment files, credentials, raw logs, private footage, generated downloads or unlicensed assets. Include provenance and the original license for new third-party code or media. Report security problems privately as described in SECURITY.md.

Contributions to Revline-authored code are provided under the repository's Apache 2.0 license. Only submit material you have the right to contribute.
