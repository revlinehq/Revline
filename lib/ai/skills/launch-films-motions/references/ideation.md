# Ideation: talk, then build

A good ideation round is one message from the agent: what is already known, at most 2–3 questions with defaults, a one-sentence message, a tension and 3–5 angles. When the user accepts an angle, building starts.

## Workflow
1. **Read what is known:** readBrief, inspectTimeline and the matching getBrandKit. Reuse the known audience, product, platform and aspect ratio, length, audio and ending.
2. **Ask** at most 2–3 missing questions, in one message, each with a default.
3. **Propose the message** in one plain sentence: what the viewer should believe.
4. **State the tension** in one sentence the audience recognises.
5. **Offer 3–5 angles** as short bullets, each one visible action plus a "Hooks because …" line of at most 15 words.
6. **Pick one** bold angle of your own and say why you like it.
7. **Build** as soon as the user accepts an angle.

## Rules

### Questions
- Without a stated length, suggest one sized to the content ("about 20 s: title, three features, end card"). An explicit length or "no logo" wins.
- Answer the user's current question in the first 1–2 sentences. Build on their ideas rather than repeating a ballot.
- Use one question to resolve the next uncertainty, for example "Is sameness the frustration you want to attack?"
- When the user asks what you have in mind, describe the proposed beats, exact copy, sound and setting in plain words.

### Message and claims
- Bad message: "Make the video you imagined without juggling tools."
- Good message, if the user confirmed that claim: "Editing software hasn't changed in 7 years. Revline is the first thing that feels different."
- Numbers and product claims follow launch-films-motions, Never speculate: check them against readBrief, or ask once.

### Metaphors
- Develop the meaning under a metaphor, not the metaphor itself.
- User: "Throw it in the trash." Bad: bin → compactor → rocket bin.
- Good: "Do you mean the old tools, or repeating the same edit? If it's repetition, I'd show seven identical timelines, then break that pattern."
- If their meaning is already clear, develop it without asking again.

### Acceptance
- "Do it", "go with that", "yes" and "that one" accept the angle they answer. The conversation ends and building starts, with no intermediate review rounds.
- Example: the agent proposes the factory; the user says "do it" → start the film code, not two more factory choices.
- Ask one clarifying question only if no angle is identifiable.
- No saved planning stage is required to build.

## Example
Tension: "Every new editor still makes you repeat the same trim."
- Seven desks replay the same trim; the eighth breaks the loop. Hooks because editors recognise the repetition before the product appears.
- A factory stamps identical timelines; one edit refuses the stamp. Hooks because the broken pattern makes the difference visible.
- One manual cut stays fixed while the surrounding edit changes. Hooks because it answers the fear of losing work to automation.

"I'd lead with the factory: you see the break before reading anything."
