# Revline

AI video editor. Describe an edit in chat, refine it on the timeline, and export your video.

## Development

Requires Node.js 22. Copy [.env.example](.env.example) to `.env.local` and configure your own development services.

```sh
npm ci
npx convex dev
```

In another terminal:

```sh
npm run dev -- --port 3001
```
